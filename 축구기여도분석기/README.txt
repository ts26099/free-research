축구 기여도 분석기
==================

경기 영상을 넣고 [분석 시작] 만 누르면 선수별 기여도까지 나옵니다.
사람이 할 일은 그 둘뿐입니다.

프로그램이 알아서 하는 것
  · 검출 모델 마련 (없으면 내려받습니다 — 처음 한 번만)
  · GPU 유무를 보고 추적 품질 결정
  · 영상에서 선수·골키퍼·심판·공 찾기            -> tracks.csv
  · 경기장 흰 선을 찾아 화면 픽셀을 미터로 변환   -> 자동 보정
  · 한 팀 인원 파악 (5 / 7 / 9 / 11명)
  · 기여도 계산 (SC · PR · PA · DPI · IPI)       -> ipi_result.xlsx

계산식은 방법론 문서 「지표 설계의 이론적 배경, 가중치, 환산 절차」의
수식 1~19 를 그대로 구현한 것입니다.


1. 실행
-------
윈도우     START.bat 더블클릭
리눅스/맥   터미널에서  bash start.sh

처음 한 번은 필요한 것을 자동으로 설치합니다.
영상 분석에 PyTorch 가 필요해서 2GB 가까이 받습니다 (10~20분, 인터넷 필요).

  ※ 이 폴더를 SoccerTracker 폴더 옆에 두면 그쪽 venv 를 그대로 쓰므로
    설치가 아예 필요 없습니다. 검출 모델도 거기서 복사해 옵니다.


2. 쓰는 법
----------
(1) 경기 영상을 창에 끌어다 놓습니다 (또는 [영상 추가])
(2) [▶ 분석 시작]

끝입니다. 나머지는 화면에 흐르는 로그를 보며 기다리면 됩니다.

  1 / 3  영상에서 선수와 공을 찾는 중
  2 / 3  경기장 보정 — 흰 선을 찾아 미터로 바꾸는 중
  3 / 3  기여도를 계산하는 중

얼마나 걸리나
  GPU 가 있으면 영상 길이와 비슷하거나 더 빠릅니다.
  GPU 가 없으면 영상 길이의 서너 배가 걸립니다 (45분 경기면 서너 시간).
  처음에는 짧은 영상으로, 또는 [고급 설정] 의 구간(12:00 ~ 15:00)으로
  잘라서 한 번 확인해 보는 것을 권합니다.


3. 결과
-------
results/<영상이름>/
├── tracks.csv        프레임별 선수·공 좌표 (화면 픽셀)
├── summary.json      추적 통계 — 추적 ID 수, 공 발견률 등
├── <영상이름>_boxes.mp4  박스를 그린 확인용 영상
├── ipi_result.xlsx   선수별 / 프레임별 / 프레임메타 / PA프레임별 / 표본검사
├── ipi_plot.png      DEF-OFF 평면 + 공간 통제 그림
└── log.txt           화면에 나온 내용 그대로

읽는 법
  IPI      최종 점수. 100 = 이 분석에 들어간 선수들의 평균, 15 = 1 표준편차
           ※ 다른 경기의 IPI 와 직접 비교할 수 없습니다 (기준이 다릅니다)
  유형     DEF-OFF 평면의 사분면. IPI 가 같아도 유형이 다르면 다른 선수입니다
  DEF_z    수비 종합 (SC 와 PR 을 합쳐 다시 표준화)
  OFF_z    공격 종합 (PA 를 표준화하고 측정 횟수로 신뢰도 보정)
  rho      신뢰도. PA 를 적게 쟀으면 평균 쪽으로 당깁니다
  IPI_adj  포지션(자기 골대까지 거리) 영향을 뺀 값


4. 분석이 끝나면 꼭 보는 두 줄
------------------------------
(1) "추적 ID 23개 (선수 22명) — 선수별 기여도를 낼 만합니다"
    이 숫자가 선수 수의 세 배를 넘으면 한 선수가 여러 번호로 쪼개진 것입니다.
    그 상태의 '선수별' 표는 선수를 가리키지 않습니다.
    -> 짧은 구간으로 다시 돌리거나, GPU 가 있는 PC 에서 돌리세요.

(2) "보정 완료 — 흰 선 (점수 0.96)"
    '흰 선' 이고 점수가 0.8 이상이면 좋습니다.
    '선수 범위(대략)' 이면 선을 못 찾아 어림잡은 것이라 거리가 부정확합니다.
    -> [고급 설정] → [손으로 보정하기] 로 기준점 4개를 직접 찍으면 정확해집니다.

자동 보정은 경기장 전체가 보이는 고정 카메라(전술 카메라)에서 잘 됩니다.
중계 화면처럼 카메라가 계속 움직이면 어렵습니다.


5. 고급 설정 (안 건드려도 됩니다)
---------------------------------
경기장      기본 105 x 68 m. 7v7 유소년이면 실제 규격으로 바꾸세요
한 팀 인원   기본 '자동' — 데이터에서 헤아립니다
구간        12:00 ~ 15:00 처럼 넣으면 그 구간만 봅니다
확인용 영상  박스를 그린 mp4 를 만들지 (용량이 큽니다)
골키퍼 제외  골키퍼는 골문 앞에 서 있는 것만으로 공간 점수를 쓸어담습니다
포지션 보정  IPI 를 '자기 골대까지 거리'로 회귀한 잔차를 함께 냅니다
PA 지수 학습 실제 패스로 지수를 추정. 순열검정을 통과할 때만 채택합니다

문서와 다르게 (기본은 둘 다 꺼짐 = 문서 그대로)
  압박 속도항에 거리 반영 — 멀리서 달려오는 것만으로 압박 점수가 붙는 것을 막습니다
  전진가치를 골대거리로 — 측면 전환 패스가 '전진 0' 으로 깎이지 않습니다
  ※ 하나라도 켜면 결과를 "문서 수식대로 계산한 값"이라 하면 안 됩니다.


6. 문제가 생겼을 때 — 진단 자료 보내기
--------------------------------------
경기 영상은 수백 MB 라 그대로 보내기 어렵습니다.
[진단 자료 만들기] 를 누르면 문제를 찾는 데 필요한 것만 2~5 MB 로 묶어 줍니다.

  · log.txt          화면에 나왔던 기록 전부
  · summary.json     추적 통계 (ID 수, 공 발견률, 설정)
  · frames/*.jpg     영상에서 뽑은 화면 6장 (가로 640px 로 줄인 사진)
  · calib/*.jpg      경기장 보정이 무엇을 보고 있는지 그린 그림
                     (잔디로 인식한 영역 + 찾아낸 흰 선)
  · counts.csv       프레임별 검출 인원 · track_life.csv  추적 ID 수명
  · tracks_sample.csv 좌표 앞부분 2천 줄
  · clip.mp4         영상 15초를 640px 로 줄인 것 (넣을지 고를 수 있습니다)

한 번이라도 분석을 돌린 뒤에 누르면 됩니다. 결과 폴더에
진단자료_<영상이름>.zip 으로 저장되고 폴더가 열립니다.


7. 안 될 때
-----------
창이 안 뜬다
  logs\crash.log 를 보세요. "tkinter 가 없습니다" 면 파이썬을 다시 설치하면서
  'tcl/tk and IDLE' 를 체크하세요.

"torch, ultralytics 가 없습니다"
  setup.bat 을 한 번 실행하세요. 또는 이 폴더를 SoccerTracker 옆에 두세요.

"축구 전용 모델을 구하지 못했습니다"
  인터넷이 막혀 있으면 일반 COCO 모델로 돕니다 — 검출이 많이 나빠집니다.
  SoccerTracker/models 의 .pt 파일을 이 폴더의 models/ 에 복사해 넣으면 됩니다.

"보정 실패"
  경기장 선이 잘 안 보이는 영상입니다.
  [고급 설정] → [손으로 보정하기] 로 기준점 4개를 클릭하세요. 한 번만 하면 됩니다.

IPI 가 대부분 비어 있다(-)
  한 팀이 관측 구간 내내 공을 갖고 있으면 한쪽은 수비 기록이, 다른 쪽은
  공격 기록이 없어 합칠 수가 없습니다. 공수가 오가는 더 긴 구간이 필요합니다.

너무 느리다
  GPU 가 없으면 원래 느립니다. 구간을 3~5분으로 잘라 쓰세요.


8. 파일 구성
------------
START.bat / start.sh   실행
setup.bat              최초 설치 (START.bat 이 알아서 부릅니다)
ipi_app.py             창
autotrack.py           1단계 — 모델 마련 + 추적 실행
tracker_core.py        검출·추적 엔진 (YOLO + ByteTrack)
draw_boxes.py          확인용 영상 그리기
autocalib.py           2단계 — 경기장 자동 보정
calibrate.py           손으로 보정하는 창 (선택)
soccer_ipi_v8.py       3단계 — 기여도 계산 엔진
pipeline.py            옆 폴더의 SoccerTracker 를 찾는 부분
diagnose.py            진단 자료 만들기
models/                검출 모델 (자동으로 채워집니다)
results/               결과
logs/                  오류 기록
